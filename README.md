# Emoji Finder

Страница поиска эмодзи, свёрстанная по макету Figma.

## Что использовано

- React
- TypeScript
- Vite
- CSS Flex и Grid
- Шрифт Inter
- Oxlint

## Как запустить

Откройте папку проекта в терминале и выполните:

```bash
npm install
npm run dev
```

Откройте ссылку, которую покажет Vite.

## Проверка

```bash
npm run build
npm run lint
```

Поиск фильтрует три карточки по названию и ключевым словам.

Макет: https://www.figma.com/design/HCciSRJI0qWzJwNoK6mb4b/Проекты-React?node-id=9249-18
